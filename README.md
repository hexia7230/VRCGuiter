🎸 VRCG
VRChatの標準ノイズ抑制やDiscordなどの通話ツールって、「ギターのきれいな高音や歌声まで削っちゃう…」こと、ありますよね。かといってノイズを切ると、エアコンの音やマイクの「サーッ」というヒスノイズがそのまま乗ってしまう。

そんな悩みを解決するのがこのVRCGuiterです！
マイクの生音の良さはそのままに、「ずっと鳴っている環境ノイズ」だけをスッキリ消して、心地よいリバーブをかけて仮想マイク VRCG としてVRChatに届けてくれます。

✨ 主な特徴

ピンポイントでノイズ除去：エアコンやホワイトノイズなどの定常音だけをカット（便利なノイズ学習方式）。

リバーブ機能：残響の「量・広さ・明るさ」を細かく調整可能。

便利なモニター機能：入力マイクの選択、出力音量の調整、入出力レベルメーター、そしてヘッドホンでのリアルタイムモニターに対応。

自動セットアップ：初回起動時に仮想マイク VRCG を自動で用意してくれます。

超軽量＆低遅延

💻 動作環境
OS: Windows 10 / 11（64bit）

初期準備: 初回起動時のみインターネット接続と管理者権限が必要です。


🚀 使い方
VRCGuiter.exe を起動します。

初回だけ「VRCGを作りますか？」と聞かれるので「はい」を選択します。

無料の仮想オーディオドライバ「VB-CABLE」を VB-Audio 公式サイト からダウンロードして導入し、録音デバイス名を VRCG に変更してください。

管理者権限の確認や、Windowsのドライバ確認画面が出るので「インストール」を選びます。

VRChat側のマイク設定で VRCG (VB-Audio Virtual Cable) を選択します。

エアコンの音などが気になるときは、ギターを弾かずに「ノイズ学習」ボタンを押して2秒ほど静かにするだけ！（設定はマイクごとに記憶されます）

🎛️ 画面の見かた
入力マイク: 音声を取り込むマイクを選びます。

排他モード: Windows側の余計なノイズ抑制やAGC（自動音量調整）を迂回します。内蔵マイクなどで音が削れちゃうときにONにしてみてください（非対応環境なら自動で通常モードに戻ります）。

ノイズ除去 強さ: 環境ノイズをどれくらいガッツリ引くかの調整です。

ゲート: 楽器を弾いていない間のわずかな残りノイズをピタッと閉じます（オフにすることも可能）。

リバーブ（量 / 広さ / 明るさ）: 残響のニュアンスを好みに合わせて調整できます。

音量: 出力ゲイン（-24 〜 +24 dB）。音割れを防ぐリミッター付きなので安心！

モニター: 処理後の音をヘッドホンで確認できます。※スピーカーで聴くとハウリングするので注意してね！

💡 設定は自動で保存されます。

⚠️ 注意点
初回起動時にWindowsから警告が出ることがあります。「詳細情報」＞「実行」から進んでください。

VB-CABLEについて: VB-Audio社の無料（ドネーションウェア）ソフトです。再配布規定の関係で本ツールには同梱していないため、公式サイトから取得してね。気に入ったらぜひVB-Audioへ寄付（ドネーション）を！

アンインストール: VB-CABLEを消したいときは、Windowsの「インストールされているアプリ」一覧からアンインストールできます。

免責事項: 本ツールはVRChatおよびVB-Audioとは一切関係のない非公式ツールです。
